# This project

**This file is yours.** `scc` ships it as a stub, records that it did, and never
touches it again — an upgrade will leave whatever you write here alone. It is most of
why `scc` needs no configuration file: the commands below are Markdown, which the
orchestrator already reads, and `scc` runs none of them.

**The delivery gate is the exception, because it is run rather than read.** Record
each of build, format, lint and test once with `scc check set <gate> "<command>"`;
`scc check` and the `pre-push` hook run them.

## Commands

```bash
# Build
uv build --wheel --out-dir dist

# Test — the whole suite
uv run pytest

# Test — one file, one class, one test (used after every task; scope, not suite)
uv run pytest tests/test_reference.py
uv run pytest tests/test_reference.py::test_diff_paths_reports_an_added_route
uv run pytest -k "ledger and not network"

# Test — the report the gate reads
uv run python scripts/test_gate.py

# Lint
uv run ruff check .
uv run ruff check . --fix

# Format / format check
uv run ruff format .
uv run ruff format --check .
```

`uv sync --all-groups` after pulling, and after any change to `pyproject.toml`.
Nothing in this project is run with a bare `python` or `pytest` — `uv run` is what
resolves the locked environment, and a bare invocation silently uses whatever
interpreter is on the path.

## Refreshing the provider schemas

```bash
uv run python scripts/refresh_reference.py           # report drift, write nothing
uv run python scripts/refresh_reference.py --write   # write it, then read `git diff reference/`
```

Exit `2` means something drifted, which is news rather than a failure.

## Conventions

- **Branch names:** `feat/<slug>`, `fix/<slug>`, `docs/<slug>`, `chore/<slug>`
- **Commits:** Conventional Commits. Scope by the area, not the file: `feat(characters)`, `fix(ledger)`, `docs(wiki)`.
- **Line length is 100.** `ruff format` settles the rest; do not hand-wrap against it.
- **What a new contributor gets wrong first:** running `pytest` without `uv run`, and
  calling a provider from a test. No test in this suite touches the network — provider
  traffic is replayed through `respx` from recorded responses under `tests/recordings/`,
  because a test that costs money per run is a test nobody runs.

## Boundaries

Not to be changed without asking:

- **`reference/`** — vendored provider schemas. Regenerated by `scripts/refresh_reference.py`,
  never hand-edited: a hand-edit is indistinguishable from a provider change and defeats
  the drift report that is the file's only reason to exist.
- **`ref/`** — other people's repositories, checked out for reading. Excluded from lint,
  format and coverage. Nothing in this project imports from it.
- **`.codegraph/`** — CodeGraph's index. Never edited, never committed.
- **The ledger format** — newline-delimited JSON with a schema version per line, appended
  and never rewritten. A reader written today has to keep working against tomorrow's
  entries; see `adr:0004-record-every-paid-call-in-a-ledger`.
